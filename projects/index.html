Featured Project  ·  2022–present
HomeEdge
A home edge-ML and IoT system built from scratch on a Raspberry Pi 4 + Pico 2W. The goal: a real sensor network that collects its own data, runs inference locally, and never phones home. Eight phases from bare MQTT node to trained anomaly detection.
// hardware manifest
brainRaspberry Pi 4
nodePico 2W (RP2350)
sensorsDHT11 · HC-SR501 · BMP180 · GL5516 · SW-520D
commsMQTT over WiFi
stackMicroPython · Python · OpenCV · TFLite · SQLite
uiStreamlit → local web UI (Phase 8)
  • P1 Pico 2W Core Node — DHT11, PIR, OLED, relay, WiFi, MQTT
  • P2 Pi Camera + OpenCV — motion detection, background subtraction, frame flagging
  • P3 TFLite Person Detection — MobileNet SSD, confidence thresholding on flagged frames
  • P4 Streamlit Dashboard — live feed, temp/humidity charts, event log, SQLite backend
  • P5 Expand Pico Node — pressure, light, tilt/tamper, buzzer, new MQTT topics
  • P6 Physical Control Panel — GPIO T-board, ADC, potentiometer thresholds, IR remote arming
  • P7 Anomaly Detection — autoencoder trained on own sensor data, pattern flagging
  • P8 Stretch — 2nd node, webhooks, servo gauge, PWM LED panel, local-only web UI
MicroPython MQTT OpenCV TFLite SQLite edge-ML IoT

Personal Project  ·  Jan–Apr 2026  ·  github.com/salcxjo/strava-ml
Strava Running ML
Four years of personal GPS/HR/cadence data → full ML pipeline → ONNX inference CLI. Classifies workout type, predicts race times, scores training readiness, and suggests next session. The whole thing runs offline from a single command.
0.875 macro F1
197 runs trained
4 classes
~200KB ONNX model
4yr data window
